#### 📈 Regression & Regularization

| Project | Description | Tech |
|--------|-------------|------|
| [House Price Prediction — Linear Regression](https://github.com/chandankgowda/kaggle_1) | End-to-end pipeline to predict residential property prices using multiple linear regression.
